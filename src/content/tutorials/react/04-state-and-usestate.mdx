# State with useState: Making Components Interactive

So far, our components have been static - they display data but can't change. That's about to change! **State** is what makes React apps come alive, letting your UI respond to user actions, API responses, and time-based events. Let's unlock the true power of React!

## What You'll Learn

- What state is and why it's essential
- How to use the useState hook
- Updating state correctly (the rules that matter)
- State with different data types
- Managing multiple pieces of state
- Common mistakes and how to avoid them

## The Problem: Variables Don't Trigger Re-renders

First, let's see why regular JavaScript variables don't work for interactive UIs:

## Enter useState: React's Memory

The `useState` hook gives your components memory that React actually tracks. When state changes, React automatically re-renders your component with the new values.

### The useState Syntax

```jsx
const [currentValue, setterFunction] = useState(initialValue);
```

- **currentValue**: The current state value
- **setterFunction**: A function to update the state (by convention, prefix with "set")
- **initialValue**: What the state starts as (only used on first render)

## The Golden Rule: Never Mutate State Directly

This is crucial - you must **never modify state directly**. Always use the setter function!

<ComparisonTable
  caption="State Updates: Right vs Wrong"
  headers={['Wrong (Mutation)', 'Right (Setter Function)']}
  rows={[
    {
      label: 'Numbers',
      values: ['count++', 'setCount(count + 1)']
    },
    {
      label: 'Arrays',
      values: ['items.push(newItem)', 'setItems([...items, newItem])']
    },
    {
      label: 'Objects',
      values: ['user.name = "new"', 'setUser({...user, name: "new"})']
    },
    {
      label: 'Booleans',
      values: ['isOpen = true', 'setIsOpen(true)']
    }
  ]}
/>

Why? Because React uses reference comparison to detect changes. If you mutate the existing object/array, React won't know anything changed!

## Updating State Based on Previous State

When your new state depends on the old state, use the **functional update** form:

```jsx
// Could be buggy with rapid clicks:
setCount(count + 1);

// Always correct - uses latest value:
setCount(prevCount => prevCount + 1);
```

<ReactEditorPreview
  initialCode={`function RapidCounter() {

    setCount(count + 1);
    setCount(count + 1);
    // You might expect +3, but you'll get +1!
  };
  
  // This version always works correctly
  const incrementCorrect = () => {
    setCount(prev => prev + 1);
    setCount(prev => prev + 1);
    setCount(prev => prev + 1);
    // Always +3!
  };
  
  const reset = () => setCount(0);
  
  return (
    <div style={{ padding: '24px', fontFamily: 'system-ui', textAlign: 'center' }}>
      <h2 style={{ color: '#111827', marginTop: 0 }}>Count: {count}</h2>

## State with Arrays

Arrays in state require immutable updates - you create new arrays instead of modifying the existing one.

<ReactEditorPreview
  initialCode={`function TodoList() {
  const [todos, setTodos] = React.useState([
    { id: 1, text: 'Learn useState', done: true },
    { id: 2, text: 'Build a project', done: false },
    { id: 3, text: 'Get hired', done: false }
  ]);
  const [newTodo, setNewTodo] = React.useState('');
  
  const addTodo = () => {
    if (!newTodo.trim()) return;
    
    // Create NEW array with spread operator
    setTodos([...todos, {
      id: Date.now(),
      text: newTodo,
      done: false
    }]);
    setNewTodo('');
  };
  
  const toggleTodo = (id) => {
    // Map creates a NEW array
    setTodos(todos.map(todo =>
      todo.id === id ? { ...todo, done: !todo.done } : todo
    ));
  };
  
  const deleteTodo = (id) => {
    // Filter creates a NEW array
    setTodos(todos.filter(todo => todo.id !== id));
  };
  
  return (
    <div style={{ padding: '24px', fontFamily: 'system-ui', maxWidth: '400px' }}>
      <h2 style={{ color: '#111827', marginTop: 0 }}>My Todo List</h2>
      
      <div style={{ display: 'flex', gap: '8px', marginBottom: '16px' }}>
        <input
          type="text"
          value={newTodo}
          onChange={(e) => setNewTodo(e.target.value)}
          onKeyPress={(e) => e.key === 'Enter' && addTodo()}

            flex: 1,

            padding: '10px 16px',
            backgroundColor: '#3b82f6',
            color: 'white',
            border: 'none',
            borderRadius: '8px',
            cursor: 'pointer',
            fontSize: '14px'
          }}
        >
          Add
        </button>
      </div>
      
      <ul style={{ listStyle: 'none', padding: 0, margin: 0 }}>
        {todos.map(todo => (
          <li 
            key={todo.id}
            style={{
              display: 'flex',
              alignItems: 'center',

  const handleAnswer = (index) => {
    setSelectedAnswer(index);
    
    setTimeout(() => {
      if (index === questions[currentQuestion].correct) {
        setScore(s => s + 1);
      }
      
      if (currentQuestion < questions.length - 1) {
        setCurrentQuestion(q => q + 1);
        setSelectedAnswer(null);
      } else {
        setShowResult(true);
      }
    }, 1000);
  };
  
  const restart = () => {
    setCurrentQuestion(0);
    setScore(0);
    setShowResult(false);
    setSelectedAnswer(null);
  };
  
  if (showResult) {
    return (
      <div style={{ 
        padding: '32px', 
        fontFamily: 'system-ui', 
        textAlign: 'center',
        backgroundColor: score === questions.length ? '#dcfce7' : '#fef3c7',
        borderRadius: '12px'
      }}>
        <h2 style={{ color: '#111827', marginTop: 0 }}>Quiz Complete!</h2>
        <p style={{ fontSize: '48px', margin: '20px 0' }}>
          {score === questions.length ? '🎉' : '📚'}
        </p>
        <p style={{ fontSize: '24px', color: '#374151' }}>
          You scored <strong>{score}</strong> out of <strong>{questions.length}</strong>
        </p>
        <button
          onClick={restart}
          style={{
            marginTop: '20px',
            padding: '12px 32px',
            fontSize: '16px',
            backgroundColor: '#3b82f6',
            color: 'white',
            border: 'none',
            borderRadius: '8px',
            cursor: 'pointer'
          }}
        >
          Try Again
        </button>
      </div>
    );
  }
  
  const q = questions[currentQuestion];
  
  return (
    <div style={{ padding: '24px', fontFamily: 'system-ui' }}>
      <div style={{ 
        display: 'flex', 
        justifyContent: 'space-between', 
        marginBottom: '20px',
        color: '#6b7280'
      }}>
        <span>Question {currentQuestion + 1}/{questions.length}</span>
        <span>Score: {score}</span>
      </div>
      
      <h2 style={{ color: '#111827', marginTop: 0 }}>{q.question}</h2>
      
      <div style={{ display: 'flex', flexDirection: 'column', gap: '10px' }}>
        {q.options.map((option, index) => {
          let bg = '#f3f4f6';
          let color = '#111827';
          
          if (selectedAnswer !== null) {
            if (index === q.correct) {
              bg = '#dcfce7';
              color = '#166534';
            } else if (index === selectedAnswer) {
              bg = '#fee2e2';
              color = '#dc2626';
            }
          }
          
          return (
            <button
              key={index}
              onClick={() => selectedAnswer === null && handleAnswer(index)}
              disabled={selectedAnswer !== null}
              style={{
                padding: '14px 18px',
                fontSize: '15px',
                backgroundColor: bg,
                color: color,
                border: '2px solid transparent',
                borderRadius: '8px',
                cursor: selectedAnswer === null ? 'pointer' : 'default',
                textAlign: 'left',
                transition: 'all 0.2s'
              }}
            >
              {option}
            </button>
          );
        })}
      </div>
    </div>
  );
}

render(<QuizApp />);`}

## Common useState Mistakes

### Mistake 1: Forgetting That State Updates Are Async

### Mistake 2: Mutating State Directly

```jsx
// WRONG - mutating the array directly
const addItem = (item) => {
  items.push(item);      // Mutates the existing array
  setItems(items);       // Same reference - React won't detect change!
};

// RIGHT - creating a new array
const addItem = (item) => {
  setItems([...items, item]);  // New array - React will re-render!
};
```

### Mistake 3: Using State When You Don't Need It

Not everything needs to be state! Use state only for values that:
1. Change over time
2. Should trigger a re-render when changed
3. Can't be computed from other state/props

```jsx
// BAD - computed value doesn't need to be state
const [fullName, setFullName] = useState('');
useEffect(() => {
  setFullName(firstName + ' ' + lastName);
}, [firstName, lastName]);

// GOOD - just compute it during render
const fullName = firstName + ' ' + lastName;
```

## Key Takeaways

1. **State is React's memory** - it persists across re-renders and triggers UI updates when changed
2. **Always use the setter** - never modify state variables directly
3. **State updates are async** - the new value isn't available immediately after calling the setter
4. **Use functional updates** when the new state depends on the previous state
5. **Keep state immutable** - create new objects/arrays instead of modifying existing ones
6. **Split independent state** - use multiple useState calls for unrelated values
