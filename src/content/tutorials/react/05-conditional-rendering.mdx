# Conditional Rendering: Showing and Hiding Content

Real apps show different things based on conditions - logged in vs logged out, loading vs loaded, empty vs has data. React makes this super easy! Let's learn all the ways to conditionally render content. 🚀

## What You'll Learn

- The ternary operator for either/or rendering
- Logical AND (&&) for show/hide patterns
- Early returns for component-level conditions
- Conditional CSS classes and styles
- Best practices for clean conditional code

## Why Conditional Rendering?

Think about a typical app:
- Show "Welcome, Sarah" if logged in, "Please sign in" if not
- Show a spinner while loading, then the actual content
- Show "No results" when a search returns empty
- Show/hide a modal based on user action

All of these need **conditional rendering**!

## Method 1: Ternary Operator

The ternary operator is perfect for **either/or** situations:

```jsx
{condition ? <ShowThis /> : <ShowThat />}
```

## Method 2: Logical AND (&&)

Use `&&` when you want to show something OR nothing:

```jsx
{condition && <ShowThis />}
// If condition is true: renders <ShowThis />
// If condition is false: renders nothing
```

### ⚠️ Watch Out: The Zero Trap

Be careful with numbers and `&&`:

```jsx
// ❌ Bug! If count is 0, it renders "0" on screen
{count && <span>{count} items</span>}

// ✅ Fix: Convert to boolean first
{count > 0 && <span>{count} items</span>}
```

## Method 3: Early Return

Use early returns to prevent entire components from rendering:

```jsx
function AdminPanel({ user }) {
  // Early return - component won't render at all
  if (!user.isAdmin) {
    return null;
  }
  
  return <div>Secret admin stuff...</div>;
}
```

## Conditional Styling

You can also conditionally apply styles and classes:

<ReactEditorPreview
  initialCode={`function StatusButton({ status }) {
  // Conditional styles based on status
  const getStyles = () => {
    const base = {
      padding: '10px 20px',
      border: 'none',
      borderRadius: '8px',
      fontWeight: '500',
      cursor: 'pointer',
      transition: 'all 0.2s'
    };
    
    switch (status) {
      case 'success':
        return { ...base, backgroundColor: '#22c55e', color: 'white' };
      case 'warning':
        return { ...base, backgroundColor: '#f59e0b', color: 'white' };
      case 'error':
        return { ...base, backgroundColor: '#ef4444', color: 'white' };
      default:
        return { ...base, backgroundColor: '#e5e7eb', color: '#374151' };
    }
  };
  
  return <button style={getStyles()}>{status}</button>;
}

function App() {
  const [currentStatus, setCurrentStatus] = React.useState('default');
  
  return (
    <div style={{ padding: '20px', fontFamily: 'system-ui' }}>
      <h3 style={{ marginTop: 0, color: '#111827' }}>Conditional Styling</h3>
      
      {/* Display current status */}
      <div style={{ marginBottom: '20px' }}>
        <StatusButton status={currentStatus} />
      </div>
      
      {/* Status selector */}
      <div style={{ display: 'flex', gap: '8px', flexWrap: 'wrap' }}>
        {['default', 'success', 'warning', 'error'].map(status => (
          <button
            key={status}
            onClick={() => setCurrentStatus(status)}
            style={{
              padding: '6px 12px',
              backgroundColor: currentStatus === status ? '#3b82f6' : '#f3f4f6',
              color: currentStatus === status ? 'white' : '#374151',
              border: 'none',
              borderRadius: '6px',
              cursor: 'pointer'
            }}
          >
            {status}
          </button>
        ))}
      </div>
    </div>
  );
}

render(<App />);`}
  title="Conditional Styling Based on Props"
  height={300}
  editable={true}
/>

## Real-World Example: Loading States

Here's a common pattern you'll use constantly:

<ReactEditorPreview
  initialCode={`function DataFetcher() {
  const [status, setStatus] = React.useState('idle'); // idle, loading, success, error
  const [data, setData] = React.useState(null);
  
  const fetchData = () => {
    setStatus('loading');
    setData(null);
    
    // Simulate API call
    setTimeout(() => {
      // Randomly succeed or fail
      if (Math.random() > 0.3) {
        setData({ 
          users: ['Sarah', 'Mike', 'Emma'],
          total: 3
        });
        setStatus('success');
      } else {
        setStatus('error');
      }
    }, 1500);
  };
  
  return (
    <div style={{ padding: '20px', fontFamily: 'system-ui', minHeight: '200px' }}>
      <button
        onClick={fetchData}
        disabled={status === 'loading'}
        style={{
          padding: '10px 20px',
          backgroundColor: '#3b82f6',
          color: 'white',
          border: 'none',
          borderRadius: '8px',
          cursor: status === 'loading' ? 'wait' : 'pointer',
          marginBottom: '20px',
          opacity: status === 'loading' ? 0.7 : 1
        }}
      >
        {status === 'loading' ? 'Loading...' : 'Fetch Data'}
      </button>
      
      {/* Loading state */}
      {status === 'loading' && (
        <div style={{
          padding: '20px',
          textAlign: 'center',
          color: '#6b7280'
        }}>
          <div style={{ fontSize: '24px', marginBottom: '8px' }}>⏳</div>
          <p>Fetching data...</p>
        </div>
      )}
      
      {/* Error state */}
      {status === 'error' && (
        <div style={{
          padding: '16px',
          backgroundColor: '#fee2e2',
          borderRadius: '8px',
          color: '#991b1b'
        }}>
          <strong>Error!</strong> Failed to fetch data. Try again.
        </div>
      )}
      
      {/* Success state */}
      {status === 'success' && data && (
        <div style={{
          padding: '16px',
          backgroundColor: '#dcfce7',
          borderRadius: '8px',
          color: '#166534'
        }}>
          <strong>Success!</strong> Found {data.total} users:
          <ul style={{ margin: '8px 0 0 0', paddingLeft: '20px' }}>
            {data.users.map(user => (
              <li key={user}>{user}</li>
            ))}
          </ul>
        </div>
      )}
      
      {/* Idle state */}
      {status === 'idle' && (
        <p style={{ color: '#6b7280' }}>
          Click the button to fetch data
        </p>
      )}
    </div>
  );
}

render(<DataFetcher />);`}

  height={400}
  editable={true}
