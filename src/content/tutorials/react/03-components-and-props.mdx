# Components and Props: Building Reusable UI Blocks

Components are React's secret sauce - they let you build reusable pieces of UI that you can use anywhere. Combined with props, you can create flexible building blocks that power entire applications. Let's learn how! 🚀

## What You'll Learn

- How to create functional components
- Passing data with props
- Default props and destructuring
- Component composition with children
- Building reusable UI patterns

## What Are Components?

Think of components as **custom HTML elements** you create yourself. Instead of being limited to `<div>`, `<button>`, and `<input>`, you can create `<UserCard>`, `<ProductList>`, or anything you need!

```jsx
// Your custom component
function WelcomeMessage() {
  return <h1>Welcome to React!</h1>;
}

// Use it like any HTML element
<WelcomeMessage />
```

## Props: Passing Data to Components

Props (short for "properties") let you pass data to components - like function arguments!

```jsx
// Define component with props parameter
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>;
}

// Pass data when using the component
<Greeting name="Sarah" />
```

## Destructuring Props (The Clean Way)

Always destructure props in the function parameters for cleaner code:

```jsx
// ❌ Verbose - accessing props.* everywhere
function Card(props) {
  return <div className={props.className}>{props.title}</div>;
}

// ✅ Clean - destructure what you need
function Card({ title, className }) {
  return <div className={className}>{title}</div>;
}
```

## The Children Prop

The `children` prop is special - it's whatever you put **between** opening and closing tags:

```jsx
<Card>
  <h2>This is children!</h2>
  <p>Everything here gets passed as props.children</p>
</Card>

// Inside Card:
function Card({ children }) {
  return <div className="card">{children}</div>;
}
```

## Component Composition

The real power of React is **composition** - building complex UIs from simple components.

<ReactEditorPreview
  initialCode={`// Small, focused components
function Avatar({ initials, size = 40 }) {
  return (
    <div style={{
      width: size,
      height: size,
      borderRadius: '50%',
      backgroundColor: '#e0e7ff',
      display: 'flex',
      alignItems: 'center',
      justifyContent: 'center',
      fontSize: size * 0.4,
      fontWeight: '600',
      color: '#4f46e5'
    }}>
      {initials}
    </div>
  );
}

function Badge({ children, variant = 'default' }) {
  const colors = {
    default: { bg: '#f3f4f6', text: '#374151' },
    success: { bg: '#dcfce7', text: '#166534' },
    warning: { bg: '#fef3c7', text: '#92400e' }
  };
  
  return (
    <span style={{
      padding: '4px 10px',
      borderRadius: '12px',
      fontSize: '12px',
      fontWeight: '500',
      backgroundColor: colors[variant].bg,
      color: colors[variant].text
    }}>
      {children}
    </span>
  );
}

// Composed component using smaller ones
function TeamMember({ name, role, status, initials }) {
  const statusVariant = {
    'Active': 'success',
    'Away': 'warning'
  }[status] || 'default';
  
  return (
    <div style={{
      display: 'flex',
      alignItems: 'center',
      gap: '12px',
      padding: '16px',
      backgroundColor: 'white',
      borderRadius: '12px',
      border: '1px solid #e5e7eb',
      marginBottom: '12px'
    }}>
      <Avatar initials={initials} />
      <div style={{ flex: 1 }}>
        <h4 style={{ margin: '0 0 4px 0', color: '#111827' }}>{name}</h4>
        <p style={{ margin: 0, fontSize: '14px', color: '#6b7280' }}>{role}</p>
      </div>
      <Badge variant={statusVariant}>{status}</Badge>
    </div>
  );
}

// App using everything together
function App() {
  const team = [
    { id: 1, name: 'Sarah Chen', role: 'Lead Dev', status: 'Active', initials: 'SC' },
    { id: 2, name: 'Mike Johnson', role: 'Designer', status: 'Away', initials: 'MJ' },
    { id: 3, name: 'Emma Wilson', role: 'PM', status: 'Active', initials: 'EW' },
  ];
  
  return (
    <div style={{ padding: '20px', fontFamily: 'system-ui', maxWidth: '400px' }}>
      <h2 style={{ color: '#111827', marginBottom: '16px' }}>Team Members</h2>
      {team.map(member => (
        <TeamMember key={member.id} {...member} />
      ))}

  );
}

## The Spread Operator for Props

Pass all properties of an object as props with the spread operator:

```jsx
const user = { name: 'Sarah', age: 28, role: 'Developer' };

// These are equivalent:
<UserCard {...user} />
<UserCard name={user.name} age={user.age} role={user.role} />
```

This is super handy when passing data from arrays!

## Rest Props Pattern

Capture extra props to pass to child elements:

<ReactEditorPreview
  initialCode={`// The ...rest pattern captures all other props
function Input({ label, error, ...rest }) {
  return (
    <div style={{ marginBottom: '16px' }}>
      {label && (
        <label style={{ 
          display: 'block', 
          marginBottom: '4px',
          fontWeight: '500',
          color: '#374151'
        }}>
          {label}
        </label>
      )}
      <input
        {...rest}  // Spreads type, placeholder, value, onChange, etc.
        style={{
          width: '100%',
          padding: '10px 12px',
          borderRadius: '8px',
          border: error ? '2px solid #ef4444' : '1px solid #d1d5db',
          fontSize: '14px',
          outline: 'none',
          boxSizing: 'border-box'
        }}
      />
      {error && (
        <span style={{ color: '#ef4444', fontSize: '12px', marginTop: '4px', display: 'block' }}>
          {error}
        </span>
      )}
    </div>
  );
}

function App() {
  const [email, setEmail] = React.useState('');
  const [password, setPassword] = React.useState('');
  
  return (
    <div style={{ padding: '20px', maxWidth: '300px', fontFamily: 'system-ui' }}>
      <h3 style={{ marginTop: 0, color: '#111827' }}>Login Form</h3>
      
      {/* All standard input props work! */}
      <Input
        label="Email"
        type="email"
        placeholder="you@example.com"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
      />
      
      <Input
        label="Password"
        type="password"
        placeholder="••••••••"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        error={password.length > 0 && password.length < 8 ? 'Min 8 characters' : ''}
      />
    </div>
  );
}

render(<App />);`}
  title="Rest Props Pattern - Pass Through Native Attributes"
