# Lists and Keys: Rendering Dynamic Data

Almost every app needs to display lists - products, users, messages, todos. React makes this easy with the `map()` method, but there's one crucial concept to master: **keys**. Let's dive in! 🚀

## What You'll Learn

- Rendering arrays with `map()`
- Why keys are essential (and what happens without them)
- Choosing the right key for your data
- Common list patterns and transformations
- Handling empty states

## Rendering Lists with map()

The `map()` array method transforms each item in an array into JSX:

```jsx
const names = ['Sarah', 'Mike', 'Emma'];

// Transform each name into a <li>
{names.map(name => (
  <li key={name}>{name}</li>
))}
```

## The Key Prop: Why It Matters

Every item in a list needs a unique `key` prop. React uses keys to:

- **Track which items changed** - efficiently update only what's needed
- **Maintain component state** - keep form inputs and animations working
- **Optimize performance** - avoid unnecessary re-renders

### ⚠️ When NOT to Use Index as Key

```jsx
// ❌ Bad - index changes when items are added/removed
{items.map((item, index) => (
  <Item key={index} data={item} />
))}

// ✅ Good - ID stays with the item
{items.map(item => (
  <Item key={item.id} data={item} />
))}
```

Index as key is only safe for:
- Static lists that never change
- No reordering, filtering, or additions/removals
- No item-level state (like form inputs)

## Interactive Lists

Most lists need interactivity - clicking, filtering, or modifying items:

<ReactEditorPreview
  initialCode={`function TodoList() {
  const [todos, setTodos] = React.useState([
    { id: 1, text: 'Learn React', completed: true },
    { id: 2, text: 'Build a project', completed: false },
    { id: 3, text: 'Deploy to production', completed: false }
  ]);
  const [newTodo, setNewTodo] = React.useState('');
  
  const addTodo = () => {
    if (!newTodo.trim()) return;
    setTodos([
      ...todos,
      { id: Date.now(), text: newTodo, completed: false }
    ]);
    setNewTodo('');
  };
  
  const toggleTodo = (id) => {
    setTodos(todos.map(todo =>
      todo.id === id 
        ? { ...todo, completed: !todo.completed }
        : todo
    ));
  };
  
  const deleteTodo = (id) => {
    setTodos(todos.filter(todo => todo.id !== id));
  };
  
  return (
    <div style={{ padding: '20px', fontFamily: 'system-ui', maxWidth: '400px' }}>
      <h3 style={{ marginTop: 0, color: '#111827' }}>Todo List</h3>
      
      {/* Add todo form */}
      <div style={{ display: 'flex', gap: '8px', marginBottom: '16px' }}>
        <input
          value={newTodo}
          onChange={(e) => setNewTodo(e.target.value)}
          onKeyDown={(e) => e.key === 'Enter' && addTodo()}
          placeholder="Add a new todo..."
          style={{
            flex: 1,
            padding: '10px 12px',
            border: '1px solid #d1d5db',
            borderRadius: '8px',
            fontSize: '14px'
          }}
        />
        <button 
          onClick={addTodo}
          style={{
            padding: '10px 16px',
            backgroundColor: '#3b82f6',
            color: 'white',
            border: 'none',
            borderRadius: '8px',
            cursor: 'pointer'
          }}
        >
          Add
        </button>
      </div>
      
      {/* Todo list */}
      <ul style={{ listStyle: 'none', padding: 0, margin: 0 }}>
        {todos.map(todo => (
          <li 
            key={todo.id}
            style={{
              display: 'flex',
              alignItems: 'center',
              gap: '12px',
              padding: '12px',
              marginBottom: '8px',
              backgroundColor: '#f9fafb',
              borderRadius: '8px'

              checked={todo.completed}

              flex: 1,

                borderRadius: '4px',
                cursor: 'pointer',
                fontSize: '12px'
              }}
            >
              Delete
            </button>
          </li>
        ))}
      </ul>
      
      {/* Stats */}
      <p style={{ fontSize: '14px', color: '#6b7280', marginTop: '12px' }}>

## Filtering and Sorting

Transform your data before rendering:

<ReactEditorPreview
  initialCode={`function ProductList() {
  const [filter, setFilter] = React.useState('all');
  const [sortBy, setSortBy] = React.useState('name');
  
  const products = [
    { id: 1, name: 'Laptop', price: 999, category: 'electronics', inStock: true },
    { id: 2, name: 'Headphones', price: 199, category: 'electronics', inStock: true },
    { id: 3, name: 'T-Shirt', price: 29, category: 'clothing', inStock: false },
    { id: 4, name: 'Sneakers', price: 149, category: 'clothing', inStock: true },
    { id: 5, name: 'Watch', price: 299, category: 'electronics', inStock: false }
  ];
  
  // Filter products
  const filteredProducts = products.filter(product => {
    if (filter === 'all') return true;
    if (filter === 'inStock') return product.inStock;
    return product.category === filter;
  });
  
  // Sort products
  const sortedProducts = [...filteredProducts].sort((a, b) => {
    if (sortBy === 'name') return a.name.localeCompare(b.name);
    if (sortBy === 'price-low') return a.price - b.price;
    if (sortBy === 'price-high') return b.price - a.price;
    return 0;
  });
  
  return (
    <div style={{ padding: '20px', fontFamily: 'system-ui' }}>
      <h3 style={{ marginTop: 0, color: '#111827' }}>Products</h3>
      
      {/* Filters */}
      <div style={{ 
        display: 'flex', 
        gap: '16px', 
        marginBottom: '16px',
        flexWrap: 'wrap'
      }}>
        <div>
          <label style={{ display: 'block', fontSize: '12px', color: '#6b7280', marginBottom: '4px' }}>
            Filter:
          </label>
          <select 
            value={filter} 
            onChange={(e) => setFilter(e.target.value)}
            style={{ padding: '6px 12px', borderRadius: '6px', border: '1px solid #d1d5db' }}
          >
            <option value="all">All</option>
            <option value="electronics">Electronics</option>
            <option value="clothing">Clothing</option>
            <option value="inStock">In Stock</option>
          </select>
        </div>
        
        <div>
          <label style={{ display: 'block', fontSize: '12px', color: '#6b7280', marginBottom: '4px' }}>
            Sort by:
          </label>
          <select 
            value={sortBy} 
            onChange={(e) => setSortBy(e.target.value)}
            style={{ padding: '6px 12px', borderRadius: '6px', border: '1px solid #d1d5db' }}
          >
            <option value="name">Name</option>
            <option value="price-low">Price: Low to High</option>
            <option value="price-high">Price: High to Low</option>
          </select>
        </div>
      </div>
      
      {/* Product list */}
      <div>
        {sortedProducts.map(product => (
          <div 
            key={product.id}
            style={{
              display: 'flex',
              justifyContent: 'space-between',
              alignItems: 'center',
              padding: '12px 16px',
              marginBottom: '8px',
              backgroundColor: 'white',
              borderRadius: '8px',
              border: '1px solid #e5e7eb'
            }}
          >
            <div>
              <div style={{ fontWeight: '500', color: '#111827' }}>{product.name}</div>
              <div style={{ fontSize: '12px', color: '#6b7280' }}>{product.category}</div>
            </div>
            <div style={{ textAlign: 'right' }}>
              <div style={{ fontWeight: '600', color: '#111827' }}>${product.price}</div>
              <div style={{ 
                fontSize: '12px', 
                color: product.inStock ? '#22c55e' : '#ef4444' 
              }}>
                {product.inStock ? 'In Stock' : 'Out of Stock'}
              </div>
            </div>
          </div>
        ))}
      </div>
      
      <p style={{ fontSize: '14px', color: '#6b7280' }}>
        Showing {sortedProducts.length} of {products.length} products
      </p>
    </div>
  );
}

render(<ProductList />);`}
  title="Filtering and Sorting Lists"
  height={480}
  editable={true}

## Handling Empty States

Always handle the case when there's no data:

<ReactEditorPreview
  initialCode={`function SearchResults() {
  const [query, setQuery] = React.useState('');
  
  const allItems = [
    { id: 1, name: 'React Tutorial', type: 'tutorial' },
    { id: 2, name: 'JavaScript Basics', type: 'tutorial' },
    { id: 3, name: 'CSS Tricks', type: 'article' },
    { id: 4, name: 'Node.js Guide', type: 'tutorial' },
    { id: 5, name: 'TypeScript Tips', type: 'article' }
  ];
  
  const results = allItems.filter(item =>
    item.name.toLowerCase().includes(query.toLowerCase())
  );
  
  return (
    <div style={{ padding: '20px', fontFamily: 'system-ui', maxWidth: '400px' }}>
      <h3 style={{ marginTop: 0, color: '#111827' }}>Search</h3>
      
      <input
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Search items..."
        style={{
          width: '100%',
          padding: '12px',
          borderRadius: '8px',
          border: '1px solid #d1d5db',
          fontSize: '14px',
          marginBottom: '16px',
          boxSizing: 'border-box'
        }}
      />
      
      {/* Conditional rendering based on results */}
      {results.length > 0 ? (
        <ul style={{ listStyle: 'none', padding: 0, margin: 0 }}>
          {results.map(item => (
            <li 
              key={item.id}
              style={{
                padding: '12px',
                marginBottom: '8px',
                backgroundColor: '#f9fafb',
                borderRadius: '8px',
                display: 'flex',
                justifyContent: 'space-between'
              }}

              <span style={{ color: '#374151' }}>{item.name}</span>
              <span style={{ 
                fontSize: '12px', 
                color: '#6b7280',
                textTransform: 'capitalize'

                {item.type}
              </span>
            </li>
          ))}
        </ul>
      ) : (
        /* Empty state */
        <div style={{
          textAlign: 'center',
          padding: '40px 20px',
          backgroundColor: '#f9fafb',
          borderRadius: '8px'
        }}>
          <div style={{ fontSize: '32px', marginBottom: '12px' }}>🔍</div>

        </p>
